Welcome to the cryptography challenges!


How to use this set of challenges:

- Click on the challenge card. If you click on hint section it will open, so don't if you want to give it a go first.

- Each challenge has an encryption or a link to a new challenge page.

- If given an encryption it is your job to try recognise what it is then decrypt the code to get a flag.

- If you are given a link to a new challenge page, open the page and look over the information given to then start trying to crack the encryption.

- At the bottom of each card there is a hint. Some hints may NEED to be used to get what the key is for an encryption or such. However it is better use to use them at the point when you either are stuck or realise that you need the hint to break the encryption NOT just because it is there.

- At the bottom of the list there is a card for tools which gives you links to pages that may help you decrypt the challenge if you do not want to write a script yourself.



In the end if you cannot solve a challenge go to the Answers page in the Menu to have a look at what the answer is and how to get there.
